A module for OpenLumara that provides an immersive text adventure game, with support for asset packs (you can make your own!), including sound effects, music, weather, skies, shaders, and more. Once installed, just ask your AI to start an adventure!

I recommend using a model like Gemma4 26b or 31b with this module, or any model optimized for story writing that also supports toolcalls. Some models are simply better at telling stories than others. Qwen 3.8 Flash Next for example just sounds like ChatGPT when writing stories, so i wouldn't recommend that. (god knows how much of that i had to endure when playtesting this)

To install, just simply paste the link to this github repo into openlumara's 'Your Modules' section, or use `/library install https://github.com/Rose22/openlumara-adventure-games-module`
